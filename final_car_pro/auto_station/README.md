# 自动工位流程梳理

本文按当前代码记录 B2 自动工位流程。所有 S4 角度均为实际写入角度，不再使用逻辑角度换算。

## 自动工位触发

| 遥控动作 | 自动流程 |
| -------- | -------- |
| CH1 左打到底 | State 1，新预夹位 |
| CH2 上推到底 | State 2，转台连贯宏 |
| CH1 右打到底 | State 3，合并预放宏 |
| CH3 上推超过 `1950` | M5 直接归顶到 `0` |

## 位置目标

| 位置 | M5 脉冲 | S1 实际角度 | S4 实际角度 |
| ---- | ------- | ----------- | ----------- |
| 新预夹位 | `119860` | `0` | `80` |
| 夹取位 | `139860` | 保持当前 | 保持当前 |
| 转台位 | `76590` | `180` | `170` |
| 转盘预夹位 | `42000` | `180` | `170` |
| 预放位 | `157000` | `0` | `60` |
| M5 顶部 | `0` | 保持当前 | 保持当前 |
| 安全高位 | `500` | 保持当前 | 保持当前 |

## State 1：CH1 左打到底，新预夹位

1. M5 到安全高位 `500`，等待 `3000ms`。
2. S1 到 `0`，S4 到 `80`。
3. 等待 `500ms`。
4. M5 到新预夹位 `119860`，等待 `3000ms`。
5. 完成，当前状态记为 State 1。

## State 2：CH2 上推到底，转台连贯宏

1. M5 到夹取位 `139860`，等待 `2000ms`。
2. 等待 `500ms`。
3. 快速闭合夹爪，S2/S3 直接写 `170`。
4. M5 到安全高位 `500`，等待 `3000ms`。
5. S1 到 `180`，S4 到转台内收角 `170`。
6. 等待 `500ms`。
7. M5 到转台位 `76590`，等待 `2000ms`。
8. 夹爪先半开到 `120`。
9. M5 到顶部 `0`，等待 `3000ms`。
10. 夹爪完全张开到 `60`。
11. M6 转盘步进一次：`motor6Pos + M6_STEP`。
12. 等待 `500ms`。
13. S1 到 `0`，S4 到预放外展角 `60`。
14. 等待 `500ms`。
15. M5 到新预夹位 `119860`，等待 `3000ms`。
16. 完成，当前状态记为 State 1。

## State 3：CH1 右打到底，合并预放宏

1. M5 到顶部 `0`，等待 `3000ms`。
2. 快速确认夹爪张开，S2/S3 直接写 `60`。
3. S4 内收到转盘角 `170`。
4. 等待 `200ms`。
5. S1 到转盘角 `180`。
6. 等待 `1000ms`。
7. M5 去转盘预夹位 `42000`。
8. 等待 `1500ms` 后提前启动夹爪闭合。
9. 快速闭合夹爪，S2/S3 直接写 `170`。
10. 闭合完成后额外等待 `1000ms`。
11. M5 到顶部 `0`，等待 `3000ms`。
12. S1 到预放角 `0`。
13. 等待 `500ms`。
14. M6 转盘反向步进一次：`motor6Pos - M6_STEP`。
15. 等待 `500ms`。
16. S4 外展到预放角 `60`。
17. 等待 `500ms`。
18. M5 到预放位 `157000`，等待 `3000ms`。
19. 完成，当前状态记为 State 3，夹爪保持当前状态。

## 夹爪模式

| 模式 | 行为 |
| ---- | ---- |
| 快速打开 | 直接写 `60` |
| 转台半开 | 直接写 `120` |
| 快速闭合 | 直接写 `170` |

自动流程中，夹爪动作都直接写目标角度，不再分步执行。
