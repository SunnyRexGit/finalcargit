# ESP32-S3 遥控小车工程

函数说明和调参入口见：[main.cpp 函数说明与调参指南](docs/main_function_guide.md)。

本项目使用 ESP32-S3 作为主控，通过 MC7RE 2.4G 接收机读取遥控器通道，通过 TTL-RS485 控制 6 个闭环步进电机，通过 PCA9685 控制 4 路舵机。项目替代旧安卓 WiFi TCP 控制方式，主控制方式改为遥控器，不依赖安卓 App，也不依赖 WiFi TCP。

当前固件采用 **M.BUS / SBUS 串行输入**：GPIO18 读取接收机信号，串口参数为 `100000, SERIAL_8E2`，默认启用反相读取。SBUS 原始通道值按 `172~1811` 映射到 `1000~2000`，中位为 `1500`。

## 完整接线表

### ESP32-S3 到 TTL-RS485

| ESP32-S3 | TTL-RS485 |
| -------- | --------- |
| GPIO16   | RX        |
| GPIO17   | TX        |
| GND      | GND       |

串口参数固定为 `115200, SERIAL_8N1`。不要把 RS485 改到其他 GPIO。

### ESP32-S3 到 PCA9685

| ESP32-S3 | PCA9685 |
| -------- | ------- |
| GPIO11   | SDA     |
| GPIO12   | SCL     |
| 3.3V/5V  | VCC     |
| GND      | GND     |

PCA9685 地址为 `0x40`，PWM 频率为 `50Hz`。不要改成 GPIO21/GPIO22。

### PCA9685 到舵机

| PCA9685 通道 | 逻辑编号 | 功能              |
| ------------ | -------- | ----------------- |
| 0            | S1       | 云台 / 机械臂旋转 |
| 1            | S2       | 夹爪一侧          |
| 2            | S3       | 夹爪另一侧        |
| 3            | S4       | 机械臂前后        |

### RS485 电机编号

| 地址 | 功能              |
| ---- | ----------------- |
| 1    | M1 底盘轮 1       |
| 2    | M2 底盘轮 2       |
| 3    | M3 底盘轮 3       |
| 4    | M4 底盘轮 4       |
| 5    | M5 机械臂升降     |
| 6    | M6 物料盘旋转     |

M1~M4 使用速度模式，M5/M6 使用绝对位置模式。

### MC7RE 到 ESP32-S3

| MC7RE               | ESP32-S3          |
| ------------------- | ----------------- |
| M.BUS / SBUS Signal | GPIO18            |
| VCC                 | 按接收机规格接 5V 或 3.3V |
| GND                 | GND               |

所有模块必须共地。接收机如果输出的不是反相 SBUS，可在 `include/config.h` 中把 `RC_SERIAL_INVERTED` 改为 `0`。

### 激光模块

| 激光模块 | ESP32-S3 |
| -------- | -------- |
| Signal   | GPIO15   |
| VCC      | 按模块规格供电 |
| GND      | GND      |

GPIO15 默认输出高电平，激光常亮；进入 B2 自动工位模式时按 `LASER_BLINK_INTERVAL_MS` 间隔闪烁。

## 遥控器通道说明

| 通道 | 默认索引宏       | 遥控器操作   | 作用                                      |
| ---- | ---------------- | ------------ | ----------------------------------------- |
| CH1  | `RC_CH1_INDEX 0` | 右摇杆左右   | 底盘横移 / S1 云台 / 自动工位选择         |
| CH2  | `RC_CH2_INDEX 1` | 右摇杆上下   | 底盘前后 / S4 前后 / 自动工位选择         |
| CH3  | `RC_CH3_INDEX 2` | 左摇杆上下   | M5 机械臂升降                             |
| CH4  | `RC_CH4_INDEX 3` | 左摇杆左右   | 底盘原地转向 / 夹爪                       |
| CH5  | `RC_CH5_INDEX 4` | 两段开关     | 大模式切换                                |
| CH6  | `RC_CH6_INDEX 5` | 两段开关或旋钮 | 子模式切换                              |

如果实测通道不对应，修改 `include/config.h` 里的 `RC_CHx_INDEX` 宏即可。例如 CH1 和 CH2 反了，就交换 `RC_CH1_INDEX` 与 `RC_CH2_INDEX`。

模式划分：

```text
CH5 < 1500：底盘 / 物料盘模式
CH5 > 1500：机械臂模式

CH6 < 1500：普通子模式
CH6 > 1500：特殊子模式
```

### A1 普通底盘模式

触发条件：`CH5 < 1500 && CH6 < 1500`

| 通道 | 功能              |
| ---- | ----------------- |
| CH1  | 底盘左右横移 `vx` |
| CH2  | 底盘前后移动 `vy` |
| CH4  | 原地转向 `w`      |
| CH3  | 为安全默认不参与  |

混控公式：

```cpp
m1 = vy - vx + w;
m2 = -vy + vx + w;
m3 = -vy - vx + w;
m4 = vy + vx + w;
```

固件会把四路输出归一化到 `-100~100`，再映射到 `0~250 RPM`。

底盘速度是线性映射：遥控器返回值离中位越远，速度百分比越大；速度百分比再线性换算成 `0~MAX_SPEED_RPM`。加速度仍由 `ACCEL_WHEEL` 固定控制，不随摇杆变化。

### A2 物料盘模式

触发条件：`CH5 < 1500 && CH6 > 1500`。进入该模式后底盘会停止。

| 遥控器操作    | 功能                         |
| ------------- | ---------------------------- |
| CH1 左打到底  | M6 左转一步，`motor6Pos -= 900` |
| CH1 右打到底  | M6 右转一步，`motor6Pos += 900` |
| CH2 下拉到底  | M6 回中，`motor6Pos = 1800`     |

这些动作都是边沿触发：摇杆打到底只触发一次，必须回中后才能再次触发。

### B1 底盘微调模式

触发条件：`CH5 > 1500 && CH6 < 1500`。该模式用于底盘低速微调，操控方式和普通底盘模式一致，但满摇杆速度被限制到 `FINE_WHEEL_CMD_MAX`。

| 通道 | 功能 |
| ---- | ---- |
| CH1  | 底盘左右横移，低速微调 |
| CH2  | 底盘前后移动，低速微调 |
| CH4  | 底盘原地转向，低速微调 |

B1 不再控制 S1/S4/M5 或夹爪；机械臂动作由 B2 自动工位流程负责。

### B2 自动工位模式

触发条件：`CH5 > 1500 && CH6 > 1500`。进入该模式后底盘停止，手动机械臂控制暂停，M5 不被 CH3 抢控制。

| 遥控器操作    | 自动动作              |
| ------------- | --------------------- |
| CH1 左打到底  | 去预夹位 State 1      |
| CH2 上推到底  | 去转台位 State 2      |
| CH1 右打到底  | 去预放位 State 3      |
| CH2 下拉到底  | 取消当前自动动作 / 急停 |

自动工位使用 `millis()` 非阻塞状态机。动作运行中不会接受新的工位指令，除非 CH2 下拉到底取消。

## 控制参数说明

主要参数集中在 `include/config.h`：

| 参数 | 当前值 / 含义 |
| ---- | ------------- |
| `WHEEL_CMD_MAX` | `100`，底盘上层速度范围为 `-100~100` |
| `FINE_WHEEL_CMD_MAX` | `15`，B1 底盘微调模式满摇杆最大速度命令 |
| `MAX_SPEED_RPM` | `250`，轮电机最大转速映射 |
| `MIN_EFFECTIVE_CMD` | `5`，小于该值视为 0 |
| `RC_DEADZONE` | `60`，遥控器摇杆死区 |
| `RC_TIMEOUT_MS` | `300`，超过该时间无有效帧触发失控保护 |
| `M5_PULSE_MIN/MAX` | M5 机械臂升降最小/最大目标脉冲数 |
| `M5_STEP` | `400`，M5 每次连续更新增加或减少的脉冲数 |
| `M6_STEP` | `900`，M6 每次转动增加或减少的脉冲数 |
| `M6_CENTER` | `1800`，M6 回中目标脉冲数 |
| `S1` | 范围 `0~180` |
| `GRIPPER_OPEN_ANGLE` | `90`，夹爪状态为 1 时写入 |
| `GRIPPER_CLOSE_ANGLE` | `150`，夹爪状态为 0 时写入 |
| `S4` | 实际角度范围 `0~180`，代码直接写入该角度 |
| `HIGH_POS` | `500`，所有 S1/S4 旋转前都会先回到该安全高位，低于 1000 脉冲 |
| 预夹位 | 详见 `auto_station/README.md` |
| 转台位 | 详见 `auto_station/README.md` |
| 预放位 | 详见 `auto_station/README.md` |
| `POSITION_SPEED_M5_AUTO` | `800`，B2 自动工位中 M5 的速度参数 |
| `AUTO_M5_MOVE_WAIT_MS` | `4000`，自动工位每次 M5 位置命令后的等待时间 |

方向反了优先改这些宏：

```cpp
#define CHASSIS_X_SIGN 1
#define CHASSIS_Y_SIGN 1
#define CHASSIS_W_SIGN 1
#define M1_SIGN 1
#define M2_SIGN 1
#define M3_SIGN 1
#define M4_SIGN 1
#define M5_DIR_SIGN 1
#define GRIPPER_S3_REVERSED 0
```

## 完整调试流程

### 第 0 步：安全准备

1. 小车架空，四个轮子离地。
2. 机械臂不要装重物。
3. 初次测试时舵机不要带负载。
4. 确认所有 GND 共地。
5. 确认 RS485 A/B 接线。
6. 确认 PCA9685 单独供电能力足够。
7. 打开 PlatformIO 串口监视器，波特率 `115200`。
8. 准备随时断电。

### 第 1 步：编译上传

```bash
pio run
pio run -t upload
pio device monitor -b 115200
```

默认环境是 `esp32-s3-devkitc-1`。如果你的开发板不是这个型号，修改 `platformio.ini` 中的 `board`。

### 第 2 步：遥控器通道测试

先只给 ESP32 和接收机供电，不接电机负载。串口会周期打印：

```text
CH1=...
CH2=...
CH3=...
CH4=...
CH5=...
CH6=...
mode=...
failsafe=...
```

逐个推动摇杆和开关，确认：

```text
CH1：右摇杆左右
CH2：右摇杆上下
CH3：左摇杆上下
CH4：左摇杆左右
CH5：模式开关
CH6：子模式开关
```

如果通道不对，修改 `RC_CHx_INDEX`。如果方向反了，先不要动接线，优先修改方向宏。

### 第 3 步：失控保护测试

1. 打开遥控器，确认通道正常。
2. 关闭遥控器。
3. 串口应该显示 `FAILSAFE TRIGGERED`。
4. M1~M6 应停止，自动工位应取消。
5. 重新打开遥控器。
6. 必须所有摇杆回中后，串口显示 `FAILSAFE CLEARED`，然后才恢复控制。

失控急停命令只在刚进入失控时发送一次，避免 RS485 总线被重复急停命令占满。

### 第 4 步：PCA9685 和舵机测试

1. 只接 PCA9685 和舵机。
2. 不装机械臂负载。
3. CH5 进入机械臂模式，CH6 进入手动模式。
4. 用 CH1 测试 S1。
5. 用 CH4 左/右打到底测试 S2/S3 夹爪状态变量，确认左打到底为闭合 `0`，右打到底为张开 `1`。
6. 用 CH2 测试 S4。
7. 如果 S4 方向反，直接调整 `include/config.h` 中对应的 S4 实际角度，或检查机械安装。
8. 如果夹爪堵转，修改 `GRIPPER_OPEN_ANGLE` / `GRIPPER_CLOSE_ANGLE`。如果 S3 方向相反，改 `GRIPPER_S3_REVERSED`。

### 第 5 步：RS485 单电机测试

1. 先只接一个底盘电机。
2. 测试 M1 正反转。
3. 再测试 M2/M3/M4。
4. 确认地址是否分别是 1/2/3/4。
5. 如果不动，检查电机地址、RS485 A/B、供电、GND。

### 第 6 步：底盘架空测试

1. 四个轮子离地。
2. CH5 进入底盘模式。
3. CH6 进入普通底盘子模式。
4. 测试前后。
5. 测试左右横移。
6. 测试原地转向。
7. 如果整体方向反，修改 `CHASSIS_X_SIGN` / `CHASSIS_Y_SIGN` / `CHASSIS_W_SIGN`。
8. 如果只有一个轮子方向反，修改对应的 `Mx_SIGN`。

### 第 7 步：M5 升降测试

1. 机械臂不要带重物。
2. CH5 进入机械臂模式。
3. CH6 进入手动模式。
4. CH3 上推，M5 应该上升，`motor5Pos` 减小。
5. CH3 下拉，M5 应该下降，`motor5Pos` 增大。
6. 确认 `M5_PULSE_MIN~M5_PULSE_MAX` 脉冲限位生效。
7. 如果方向反，修改 `M5_DIR_SIGN`。

### 第 8 步：M6 物料盘测试

1. CH5 进入底盘模式。
2. CH6 进入物料盘模式。
3. CH1 左打到底，M6 左转一步 `900`。
4. CH1 右打到底，M6 右转一步 `900`。
5. CH2 下拉到底，M6 回中到 `1800`。
6. 确认必须摇杆回中后才能再次触发。

### 第 9 步：机械臂手动测试

1. CH5 进入机械臂模式。
2. CH6 进入手动模式。
3. CH1 控制底盘左右横移，速度应明显低于普通底盘模式。
4. CH2 控制底盘前后移动，速度应明显低于普通底盘模式。
5. CH4 控制底盘原地转向，速度应明显低于普通底盘模式。

### 第 10 步：自动工位测试

1. CH5 进入机械臂模式。
2. CH6 进入自动工位模式。
3. CH1 左打到底 -> 预夹位。
4. CH2 上推到底 -> 转台位。
5. CH1 右打到底 -> 预放位。
6. CH2 下拉到底 -> 取消 / 急停。
7. 观察串口是否按 `AUTO_STEP` 顺序执行。

自动工位现在所有切换都会先让 M5 回到 `HIGH_POS = 500`，等待 `AUTO_M5_MOVE_WAIT_MS`，再旋转 S1/S4，最后移动 M5 到目标位置，避免机械臂主轴旋转时碰撞。如果 B2 反应慢，优先调小 `AUTO_M5_MOVE_WAIT_MS`；如果旋转前 M5 还没完全回高位，就调大它。

夹爪在自动工位中的状态规则：去预夹位 State 1 时，M5 回到 `HIGH_POS` 后夹爪状态设为 `1=张开`；去转台位 State 2 或预放位 State 3 时，自动动作一启动就先把夹爪状态设为 `0=闭合`，再抬升 M5。

### 第 11 步：完整作业流程测试

1. 底盘移动到目标物附近。
2. 进入预夹位。
3. 使用 B1 底盘微调模式对准夹取位置。
4. 夹爪闭合。
5. 转到转台位。
6. M6 物料盘旋转。
7. 底盘移动到放置区。
8. 进入预放位。
9. 夹爪打开。

## 常见问题排查

### 1. 遥控器通道没有变化怎么办

检查接收机是否输出 SBUS/M.BUS，信号线是否接到 GPIO18，遥控器和接收机是否已对频。确认 `RC_SERIAL_INVERTED` 是否符合接收机输出。

### 2. SBUS / M.BUS 没有数据怎么办

先只接 ESP32 和接收机，打开串口监视器。如果始终 failsafe，尝试把 `RC_SERIAL_INVERTED` 改为 `0`，或者确认接收机输出协议不是 PWM 单通道。

### 3. 舵机乱甩怎么办

检查 PCA9685 电源是否独立且电流足够，GND 是否共地。首次测试不要带机械负载，并缩小舵机角度范围。

### 4. S4 方向反了怎么办

S4 现在直接使用实际角度，不再做 `180 - angle` 换算。如果方向不符合预期，检查连杆安装方向，或直接调整自动工位中的 S4 实际角度参数。

### 5. 夹爪堵转怎么办

减小 `GRIPPER_CLOSE_ANGLE` 或增大 `GRIPPER_OPEN_ANGLE` 的安全余量。如果 S3 与 S2 应该反向运动，把 `GRIPPER_S3_REVERSED` 改为 `1`。

### 6. M5 一上电乱跑怎么办

确认 M5 没有在 `setup()` 中清零。本项目只给 M1~M4 清零，M5/M6 保持原有位置记忆。检查驱动器地址、绝对位置模式和机械限位。

### 7. M5 升降方向反了怎么办

修改 `M5_DIR_SIGN`。当前 `motor5Pos` 直接表示 M5 目标脉冲数：CH3 上推时 `motor5Pos -= M5_STEP`，CH3 下拉时 `motor5Pos += M5_STEP`。

### 8. 底盘前后左右方向反了怎么办

修改 `CHASSIS_X_SIGN`、`CHASSIS_Y_SIGN` 或 `CHASSIS_W_SIGN`。如果只是某个轮反了，改对应的 `M1_SIGN` 到 `M4_SIGN`。

### 9. 四个轮子有一个方向不对怎么办

确认电机地址是否正确。如果地址正确，修改对应轮子的 `Mx_SIGN`。

### 10. RS485 电机没响应怎么办

检查电机地址、TTL-RS485 模块供电、A/B 接线、GND 共地、串口波特率。串口会打印电机返回值：`0x02` 表示 OK，`0xE2` 表示参数错误，`0xEE` 表示格式错误。

### 11. 关闭遥控器后电机还在动怎么办

确认接收机在失控时是否输出 SBUS lost frame / failsafe 标志。即使没有标志，固件也会在 `RC_TIMEOUT_MS = 300` 毫秒无有效帧后触发急停。

### 12. PlatformIO 编译库找不到怎么办

检查网络和 PlatformIO 库安装。依赖写在 `platformio.ini`：

```ini
lib_deps =
    adafruit/Adafruit PWM Servo Driver Library
```

### 13. PCA9685 检测不到怎么办

检查 SDA=GPIO11、SCL=GPIO12、地址 `0x40`、VCC、GND。PCA9685 舵机电源和逻辑电源要按模块说明连接，且所有模块共地。

## 继承关系总结

继承自旧 ESP32Robot.ino：

```text
RS485 GPIO16/GPIO17
RS485 115200 SERIAL_8N1
PCA9685 GPIO11/GPIO12
PCA9685 地址 0x40，频率 50Hz
SERVOMIN = 102，SERVOMAX = 512
M1~M6 地址 = 1~6
S1~S4 通道 = 0~3
电机使能、停止、清零、速度、绝对位置命令格式
只给 M1~M4 清零，M5/M6 不清零
```

继承自旧安卓端：

```text
底盘混控逻辑
S1 初始 180，步长 5
S2/S3 打开 90，闭合 150
S4 直接按实际角度写入
M5 现已改为直接脉冲控制，步长 M5_STEP
M6 现已改为直接脉冲控制，步长 M6_STEP，回中 M6_CENTER
HIGH_POS = 500
预夹位、转台位、预放位参数和切换顺序
```

需要实机微调的地方：

```text
SBUS 是否需要反相
RC_CHx_INDEX 通道顺序
底盘方向宏和单轮方向宏
M5_DIR_SIGN
夹爪开合角度和 GRIPPER_S3_REVERSED
自动工位 M5/S1/S4 目标位置
PCA9685 舵机脉宽 SERVOMIN/SERVOMAX
```

第一次上电前必须检查：
